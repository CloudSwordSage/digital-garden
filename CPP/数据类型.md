## 整型
> 整型是保存**整数**的数据类型

| 数据类型 | 关键字       | 字节数                                | 有符号取值范围                                                  | 无符号取值范围                                      |
| ---- | --------- | ---------------------------------- | -------------------------------------------------------- | -------------------------------------------- |
| 短整型  | short     | 2                                  | $-2^{15}$ ~ $2^{15}-1$                                   | $0$ ~ $2^{16}-1$                             |
| 整型   | int       | 4                                  | $-2^{31}$ ~ $2^{31}-1$                                   | $0$ ~ $2^{32}-1$                             |
| 长整型  | long      | 4(Windows/32位Linux)<br>8(64位Linux) | 4字节:$-2^{31}$ ~ $2^{31}-1$<br>8字节:$-2^{63}$ ~ $2^{63}-1$ | 4字节:$0$ ~ $2^{32}-1$<br>8字节:$0$ ~ $2^{64}-1$ |
| 长长整型 | long long | 8                                  | $-2^{63}$ ~ $2^{63}-1$                                   | $0$ ~ $2^{64}-1$                             |
```cpp
short a = 10;          // 短整数，16位整数
int b = 100;           // 整数，32位整数
long c = 1000;         // 长整数，32/64位整数
long long d = 1000000; // 长长整数，164位整数

unsigned short ua = 10;          // 无符号短整数，16位整数, 不可为负数
unsigned int ub = 100;           // 无符号整数，32位整数, 不可为负数
unsigned long uc = 1000;         // 无符号长整数，32/64位整数, 不可为负数
unsigned long long ud = 1000000; // 无符号长长整数，164位整数, 不可为负数
```

## sizeof 关键字

> 目的是统计数据类型实际占用的内存大小

语法: `sizeof(变量 / 数据类型)` 
例如:
```cpp
int a = 10;
std::cout << "sizeof(a) = " << sizeof(a) << std::endl;
std::cout << "sizeof(int) = " << sizeof(int) << std::endl;

std::cout << "sizeof(short) = " << sizeof(short) << std::endl;
std::cout << "sizeof(long) = " << sizeof(long) << std::endl;
std::cout << "sizeof(long long) = " << sizeof(long long) << std::endl;
```
```shell
$> g++ ./sizeof.cpp -o sizeof
$> ./sizeof
sizeof(a) = 4
sizeof(int) = 4
sizeof(short) = 2
sizeof(long) = 4  # 我的编译环境是Win, 因此是4位, 若是Linux64, 则是8
sizeof(long long) = 8
$> 
```
## 浮点数
> 保存**小数**的数据类型

| 数据类型 | 关键字    | 字节数 | 取值范围(绝对值)                                | 有效数字   |
| ---- | ------ | --- | ---------------------------------------- | ------ |
| 单精度  | float  | 4   | $1.4\cdot10^{-15}$ ~ $3.4\cdot10^{38}$   | ~7     |
| 双精度  | double | 8   | $1.7\cdot10^{-308}$ ~ $1.7\cdot10^{308}$ | ~15/16 |

```cpp
float a = 3.14159f;  // 编译器看到小数默认为双精度, 而尾部增加f即告诉编译器它是单精度
double b = 3.14159265358979323846;
```
> 可能能够发现, 上述代码中`float` 的小数尾部增加了一个 `f`
> 这是因为编译器看到小数默认为双精度, 而尾部增加f即告诉编译器它是单精度

```cpp
auto a = 3.14;
auto b = 3.14f;
std::cout << "sizeof(a) = " << sizeof(a) << std::endl;
std::cout << "sizeof(b) = " << sizeof(b) << std::endl;
```
```shell
$> g++ ./floating.cpp -o floating
$> ./floating
sizeof(a) = 8
sizeof(b) = 4
$> 
```
可以明显的看到尾部没加 `f` 的变量有8字节, 代表它为 `double`
## 字符型
> 用于保存单个字符

语法: `char a = 'a';` 
> 但需要注意, char只有1字节, 也就是只能保存单个ascii字符, 其余多字节字符无法存储

```cpp
char a = 'a';
std::cout << "a = " << a << std::endl;
std::cout << "sizeof(char) = " << sizeof(a) << std::endl;

char b = 'ab';
std::cout << "b = " << b << std::endl;
```
```shell
$> g++ ./char.cpp -o char
E:/CPP/DataType/char.cpp:13:14: warning: multi-character character constant [-Wmultichar]
   13 |     char b = 'ab';
      |              ^~~~
E:/CPP/DataType/char.cpp: In function 'int main()':
E:/CPP/DataType/char.cpp:13:14: warning: overflow in conversion from 'int' to 'char' changes value from '24930' to '98' [-Woverflow]
$> ./char
a = a
sizeof(char) = 1
b = b
sizeof(char) = 1
$> 
```
> 可以看出来单引号只能存储单个字符, 但是我们知道, 双引号可以存储多字符, 那么我们用char接收一下双引号多字符呢?

```cpp
char a = "ab";
std::cout << "a = " << a << std::endl;
```
```shell
$> g++ ./char.cpp -o char
E:/CPP/DataType/char.cpp: In function 'int main()':
E:/CPP/DataType/char.cpp:10:14: error: invalid conversion from 'const char*' to 'char' [-fpermissive]
   10 |     char a = "ab";
      |              ^~~~
      |              |
      |              const char*
$> 
```
> 这次直接error了, 通过堆栈跟踪来看, 多引号实际是以const char\*存储的, , 也就是实际为char指针, 那我们用const char\*接收一下呢

```cpp
const char * a = "ab";
std::cout << "a = " << a << std::endl;
std::cout << "sizeof(a) = " << sizeof(a) << std::endl;
std::cout << "strlen(a) = " << strlen(a) << std::endl;  // 请包含cstring头文件
```
```shell
$> g++ ./char.cpp -o char
$> ./char
a = ab
sizeof(a) = 8
strlen(a) = 2
$> 
```
> 现在成功的输出了, 且变成了8字节, 这个8字节是指针本身的字节数, 64位系统下永恒为8, 而strlen明确说明了它存了2个字符(PS: 实际上存了3个, 还有一个是\\0, 即作为结束标志)

## 字符串
> 用于表示一串字符

```cpp
char a[] = "Hello Char Array";  // C 语言风格的字符数组
std::cout << "a = " << a << std::endl;
std::string b = "Hello String";  // C++ 引入的字符串类型, 需要包含string头文件
std::cout << "b = " << b << std::endl;
```
```shell
$> g++ ./strings.cpp -o strings
$> ./strings
a = Hello Char Array
b = Hello String
$> 
```

## 布尔
> 仅仅表示真假两种状态

其只有两个值:
- true(本质为1)
- false(本质为0)
需要注意的是bool类型占用一个字节而不是一个比特
```cpp
bool a = true;
std::cout << "a = " << a << std::endl;
bool b = false;
std::cout << "b = " << b << std::endl;
std::cout << "sizeof(bool) = " << sizeof(bool) << std::endl;
```
```shell
$> g++ ./bool.cpp -o bool
$> ./bool
a = 1
b = 0
sizeof(bool) = 1
$> 
```
