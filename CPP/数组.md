## 一维数组

### 定义

> 数组中的每个元素都是相同的数据类型
> 数组中的元素在内存空间中是连续的, 是**顺序存储**类型

```cpp
int a[5];
for (int i = 0; i < 5; i++) {
	a[i] = i + 1;  // 数组元素是从0开始索引的
}
int b[5] = {6, 7, 8, 9, 10};
int c[] = {11, 12, 13, 14, 15};
std::cout << "a[0] = " << a[0] << std::endl;
std::cout << "b[0] = " << b[0] << std::endl;
std::cout << "c[0] = " << c[0] << std::endl;
```
```shell
$> g++ ./definition.cpp -o definition
$> ./definition
a[0] = 1
b[0] = 6
c[0] = 11
$> 
```
### 数组名的作用
- 可以统计数组的长度
- 可以获取数组在内存中的首地址
```cpp
int arr[10];
for (int i = 0; i < 10; i++) {
	arr[i] = i + 1;
}

std::cout << "sizeof(arr) = " << sizeof(arr) << std::endl;
std::cout << "sizeof(arr[0]) = " << sizeof(arr[0]) << std::endl;
std::cout << "sizeof(arr) / sizeof(arr[0]) = "
		  << sizeof(arr) / sizeof(arr[0]) << std::endl;

std::cout << "首地址 = " << arr << std::endl;
std::cout << "arr[0]的地址 = " << &arr[0] << std::endl;
std::cout << "arr[1]的地址 = " << &arr[1] << std::endl;
int * p = reinterpret_cast<int *>(
	reinterpret_cast<char *>(&arr[0]) + sizeof(int)
); // C++ 的指针运算的+n会根据类型大小进行偏移,
   // 这里转成char*是因为char*是单字节的, 符合偏移4字节的演示
   // 这行代码等价于int * p = &arr[0] + 1
std::cout << "*p = " << *p << std::endl;
```
```shell
$> g++ ./name.cpp -o name
$> ./name
sizeof(arr) = 40
sizeof(arr[0]) = 4
sizeof(arr) / sizeof(arr[0]) = 10
首地址 = 0x73ba5ffb60  # 对于地址来说, 每次运行均是不同的
arr[0]的地址 = 0x73ba5ffb60  # 数组首地址等价于首个元素的地址
arr[1]的地址 = 0x73ba5ffb64  # 相邻两个元素的地址差值是元素类型的字节数
*p = 2  # 偏移4字节后刚好等于arr[1]
$> 
```
